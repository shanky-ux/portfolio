# Ravi Shankar · Portfolio Website

Premium dark glassmorphism portfolio — HTML, CSS, JavaScript (no frameworks).

## Folder Structure
```
portfolio/
├── index.html
├── style.css
├── script.js
└── assets/
    ├── images/   ← drop your profile photo here (name it profile.jpg)
    └── icons/    ← custom icons if needed
```

## Quick Start
1. Open `index.html` in any browser — no build step required.
2. To add a real profile photo, place it at `assets/images/profile.jpg`
   and update the `.profile-frame` element in `index.html`.
3. Update social links, resume link, and contact details inside `index.html`.

## Features
- Animated particle canvas background
- Custom cursor with magnetic ring
- Typing effect (Hero)
- Scroll-reveal animations
- Animated skill progress bars
- Animated stat counters
- Full contact form with validation
- Glassmorphism cards throughout
- Fully responsive (mobile, tablet, desktop)
- Hamburger nav for mobile
- Scroll-to-top button
- Loader screen

## Customisation
All colours are CSS variables in `:root` inside `style.css` — change `--cyan` and `--violet` to retheme the whole site instantly.
